\# 🎯 01 — Number Guessing Game



A fun guessing game where the computer generates a random number and the player keeps guessing until the correct number is found.



\### ✨ Features



\- 🎲 Random number generation

\- 🎚️ Easy, Medium and Hard difficulty levels

\- ⬆️ Too High / Too Low hints

\- 🏆 Displays attempts

\- 🌐 Web version included
