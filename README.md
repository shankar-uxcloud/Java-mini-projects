## 🌟 About This Repository

This repository contains **5 Java programming projects** developed during my **Java Programming Internship at SAM AI Technologies**.

The projects started as core Java programming assignments and evolved into browser-based applications with responsive interfaces, interactive functionality, React development, version control, automated deployment, and live GitHub Pages hosting.

The goal was not only to complete the programming tasks, but to transform each solution into a **usable, presentable, and deployable application**.
